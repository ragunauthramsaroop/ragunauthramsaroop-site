# Durable executive graph and language access

The executive claim graph is generated from api/v1/executive-record.json, never inferred from other page text. Every claim-to-evidence link is an explicitly published relationship. Nodes distinguish the subject, AGM Inc., career claims, company-level context and evidence-source URLs. The explicit company relationship prevents misleading attribution of corporate solar and employment outcomes as individual achievements.

The JSON route /api/v1/claim-graph.json remains an unsigned self-published representation. Neither graph membership nor a source URL establishes an academic appointment, employment verification, award issuance, signature validity or factual truth. A responsible reviewer opens the underlying document and checks its precise scope.

Spanish, Portuguese and French pages provide short public-record orientation, each with a self-canonical URL and reciprocating hreflang references. English stays authoritative. These are manually authored summaries, not complete translations of the career record and not certified legal translations. Future substantive changes require reviewing all summaries, source links and dates.

Private executive briefing content is handled separately by the browser-only session room. No stored briefing contents should enter this repo, URL parameters, analytics, server requests, logging or GitHub issues. Manual printing remains the user's decision.
