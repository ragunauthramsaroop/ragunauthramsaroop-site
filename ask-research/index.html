    How the assistant works

    Useful answers without hiding the evidence.

    01

    Searches approved public material

    The first release searches a curated index of research, white papers, sector perspectives and the public executive record.

    02

    Returns source links

    Every useful response points back to the relevant publication or website page so readers can inspect the underlying material.

    03

    Keeps inference separate from evidence

    The evidence layer works locally in the browser. Optional AI reasoning runs only through a secured gateway. If no gateway is enabled, the local evidence search stays active.
